# Catalyst

Ek SaaS/analytics platform ka landing page — HTML, CSS, aur JavaScript se 
banaya, modern SaaS design patterns aur interactive UI components practice 
karne ke liye.

## Live Demo
[[LIVE_LINK]](https://sudias69.github.io/catalyst/)

## Sections
- Hero section with key stats ($2.4M, 48,291, 42Ms)
- Performance/Depth section
- Engine/features section
- Pricing plans with working Monthly/Yearly toggle
- FAQ accordion (individual toggle + Expand All/Collapse All)
- CTA banner

## Features
- Dynamic pricing toggle — switches between monthly and yearly rates (JavaScript)
- Interactive FAQ accordion with expand/collapse-all controls (JavaScript)
- Fully responsive single-page layout

## Tech Stack
HTML, CSS, JavaScript (ES6)
